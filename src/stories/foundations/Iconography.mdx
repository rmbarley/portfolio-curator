# Iconography

**Library:** [Lucide](https://lucide.dev) — open-source, tree-shakeable, stroke-based SVGs. Integrated via `@lucide/astro` which provides typed Astro components for each icon.

**Sizing rules:**
- **14px** — trailing external-link indicator on `Link`
- **16px** — inline icons in prose or nav
- **20px** — icons inside buttons (per the `Button` atom spec)
- **24px** — maximum for decorative standalone use

All icons are `aria-hidden="true"`. Meaning is conveyed by adjacent text — never by the icon alone.

## Rules

- **Never use an icon as the only label.** Always pair with visible text or an `aria-label` on the parent element.
- **`aria-hidden="true"` on every icon SVG.** The icon is decorative; the text does the communicating.
- **Don't scale icons outside the sizing rules.** 14/16/20/24px. The stroke weight (2px) is tuned for these sizes — scaling to 32px looks wrong.
- **Don't import Lucide icons not in the working set** without a real design need. Every import is a bundle cost, even with tree-shaking.
