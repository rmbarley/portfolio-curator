# Color Tokens

Every UI color in the system is a CSS custom property. There are no one-off hex values in component stylesheets — if it's a color, it's one of these tokens.

The left swatch is **dark mode**, the right is **light mode**. Toggle the theme in the Storybook toolbar to see each in context.

## Rules

- **One accent.** `--accent` is violet. `--highlight` is gold. They are not interchangeable — gold means NoAI or staleness, violet means interactivity.
- **Never use hex in component stylesheets.** Reference the token. If no token fits, add one here.
- **Contrast is the tokens' job.** The token pairs (`--bg`/`--text`, `--surface`/`--text-muted`) are tuned to pass WCAG AA in both modes. Don't override them to "soften" the UI — adjust the token values in `design-tokens.css` instead.
