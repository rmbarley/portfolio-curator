# Type Scale

Eight fluid steps, from `--step--1` (labels) to `--step-6` (hero heading). All values are `clamp()` expressions that interpolate smoothly between a 360px and 1280px viewport — there are no breakpoint jumps.

Each step shows the same sample text in **Fraunces** (display, variable) above and **Geist** (sans, variable) below.

## Usage rules

- **Display font for headings only.** Don't use Fraunces for body copy, labels, or UI chrome. Geist is the workhorse.
- **`text-wrap: balance`** is applied to h1/h2 by the Heading atom. It prevents ragged orphaned last lines on multi-line headings.
- **`text-wrap: pretty`** is applied to `<p>` in the base reset. Never apply it to headings — it can produce unexpected wrapping.
- **`--step--1` is the UI floor.** Never go below it. If something needs to be smaller, reconsider the design rather than shrinking the type.
